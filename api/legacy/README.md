# Legacy файлы

Эта папка содержит старые файлы из предыдущей версии архитектуры.

## Файлы

- `ingest.py` - Старая версия индексации (заменена на `chroma/ingest.py`)
- `query.py` - Старая версия поиска (заменена на `chroma/search.py` и `chroma/hybrid.py`)
- `server.py` - Старая версия сервера (заменена на `main.py`)

## Удаление

Эти файлы можно безопасно удалить после проверки, что новая архитектура работает корректно.
