# Руководство по использованию Postman коллекции

## Обновление коллекции v2.0

Коллекция обновлена с учетом всех новых возможностей API.

## Структура коллекции

### 📁 Health & Status
- **Health Check** - Проверка состояния API и ChromaDB

### 📁 Ingest
- **Индексация данных (API)** - `/api/ingest` - новый эндпоинт
- **Индексация данных (Legacy)** - `/ingest` - для обратной совместимости

### 📁 RAG - Поиск и ответы
- **Ask Question (Векторный поиск)** - `/api/ask` - стандартный векторный поиск
- **Ask Question (Гибридный поиск)** - `/api/ask` с `use_hybrid: true` - комбинация BM25 + векторный
- **Ask - Коллтрекинг** - пример вопроса
- **Ask - Оповещения Email** - пример вопроса
- **Ask - Яндекс.Карты** - пример вопроса
- **Ask - Динамическая загрузка** - пример вопроса
- **Ask (Legacy)** - `/ask` - для обратной совместимости

### 📁 Embed
- **Создать эмбеддинг** - `/api/embed` - создание эмбеддингов для текста

### 📁 Debug
- **Debug Search (Векторный)** - `/api/debug/search` - отладочный векторный поиск
- **Debug Search (Гибридный)** - `/api/debug/search` с `use_hybrid: true` - отладочный гибридный поиск

## Использование

### 1. Импорт коллекции

1. Откройте Postman
2. Нажмите **Import**
3. Выберите файл `Postman_Collection.json`
4. Выберите файл `Postman_Environment.json` (опционально)

### 2. Настройка окружения

Переменная `base_url` по умолчанию: `http://localhost:9001`

Для изменения:
1. Выберите окружение "RAG Pinbox Local"
2. Измените значение `base_url` при необходимости

### 3. Порядок выполнения запросов

1. **Health Check** - проверьте, что API работает
2. **Индексация данных** - выполните перед первым использованием
3. **Ask Question** - задавайте вопросы

### 4. Примеры использования

#### Векторный поиск (по умолчанию)
```json
POST /api/ask
{
    "q": "Как настроить оповещения?"
}
```

#### Гибридный поиск (лучше для фактической документации)
```json
POST /api/ask
{
    "q": "Как настроить оповещения?",
    "use_hybrid": true
}
```

#### Отладочный поиск
```json
POST /api/debug/search
{
    "q": "оповещения",
    "top_k": 5,
    "use_hybrid": false
}
```

#### Создание эмбеддинга
```json
POST /api/embed
{
    "text": "тестовый текст"
}
```

## Новые возможности

### Гибридный поиск
Используйте `"use_hybrid": true` в запросах `/api/ask` для комбинации BM25 и векторного поиска. Обычно дает лучшие результаты на фактической документации.

### Кэширование
Повторные запросы с одинаковыми вопросами автоматически используют кэш, что значительно ускоряет ответ (до 67x быстрее).

### Debug endpoints
Используйте `/api/debug/search` для детального анализа результатов поиска при разработке и оптимизации.
